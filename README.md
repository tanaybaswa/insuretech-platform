# insuretech-platform

VizCo — InsureTech AI insurance information broker.

## Status

- Next.js app shell: `web/`
- Product phase roadmap: [`docs/product/phase-roadmap.md`](docs/product/phase-roadmap.md)

## Local / Cloud Agent

```bash
cd web
npm install
npm run dev
```

App listens on `http://0.0.0.0:3000`. In a Cloud Agent session, open the
**Forwarded Ports** menu and forward port `3000` to preview it.
